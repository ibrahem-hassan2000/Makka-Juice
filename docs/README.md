[08-changelog.md](08-changelog.md).

Conventions
- New topic → next number (`10-…md`) + a row in this table. No loose `.md` files elsewhere.
- Facts about the brand must cite a source in 01. Anything invented (copy, colours, recipes) is marked **placeholder**.
- Root [CLAUDE.md](../CLAUDE.md) is the short entry point for AI sessions.
