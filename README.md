# عصير مكة — Makka Juice (concept site)

Cinematic, scroll-driven concept website for Makka Juice, Alexandria. Unofficial preview built for a pitch.

```bash
npm install
npm run dev      # local dev server
npm run build    # production build → dist/
```

All documentation — research, identity, architecture, motion spec, assets, roadmap — is in [`docs/`](docs/README.md).
